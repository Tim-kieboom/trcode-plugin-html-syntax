# HTML

Syntax highlighting for HTML (`.html`, `.htm`, `.xhtml`), in the colors of your theme: tags, attributes, values, doctype and comments. It is the tree-sitter grammar of HTML and its query, with no code. The text of a `<script>` is colored as JavaScript and the text of a `<style>` as CSS (turn the CSS plugin on too).

Needs a TerminalCode that has plugin API 1.13 (0.12.0 or later).
